# The files of this game's forks where its changes and N64Recomp-browser's web support meet, one per line: <project> <path in
# its checkout>. tools/build_web.sh applies N64Recomp-browser's patches without them, then web/patches/<project>.patch,
# the web support hand-merged over its code in them, then what N64Recomp-browser changed in them since the commit
# below (apply.cmake --since).
# plume_vulkan.cpp and .h, and plume_render_interface.h: the game's plume answers a lost Vulkan device its own way
# (its isLost() and checkLost()), which the web's is merged into.
# rt64_vi.cpp, rt64_workload.h, rt64_workload_queue.cpp and rt64_vi_renderer.cpp: the game's RT64 has a framebuffer's
# pixel aspect of its own (its VI::pixelAspect() from the VI's regions, ROGUESQ_VI_PIXEL_ASPECT, the aspect ratios
# as displayed, VI space widened in hdSize), which the web's is merged into: those keep the game's.
# plume_webgpu.cpp and .h, and the WebGPU parts of rt64: the game's own browser build has a WebGPU backend of its own
# (PLUME_WEBGPU_ENABLED, RT64_WEBGPU), which the page doesn't define: its files are the web's whole, and the rest keeps
# the game's code beside the web's.
# addresses.hpp: the page's RDRAM is the web's 512 MB, which RDRAM_OFFSET wraps a 32-bit host's addresses into, not
# the 64 MB of the game's own browser build.
# pak.cpp: the game's runtime traces each osPfs call (its lines off), and the web's Controller Pak replaces each one, so
# this patch puts upstream's file back and the web's pak is merged over it.
# rt64_state.cpp: the game skips copying a colour image to RAM on its own conditions (ROGUESQ_SKIP_COLOR_READBACK,
# its address gate), which the web's late copy of depth buffers alone (renderToRAMLateDepthOnly) is added to.
# rt64_transform_processor.cpp: the game takes a paired transform's frame before through its own rs64PrevInFrame(),
# and the web's unpaired one moved with the camera (RT64_MOVE_UNPAIRED_WITH_CAMERA) takes its own.
# merged from N64Recomp-browser d428740d51d376f1e909dc6ca1fe78653deae75b
